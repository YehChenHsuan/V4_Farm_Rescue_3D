# 牧場救援隊 · Farm Rescue 3D

瀏覽器 3D Web Game，適合電腦接投影機或觸控大螢幕。2–4 隊輪流作答，全班原地比手指、數動物、跟讀句子。無帳號、無攝影機，不會自動辨識全班手勢或評分發音。

## 開啟

目前本機網址：http://127.0.0.1:8764

日後可在此資料夾執行 `powershell -ExecutionPolicy Bypass -File .\serve.ps1`，保持伺服器視窗開啟，再用 Chrome 或 Edge 開啟上述網址。亦可使用任何支援 JavaScript modules 的靜態網站伺服器。請勿直接雙擊 HTML 使用 file://。

## 教材與模式

- 課本原題：V4 Lesson 4，第 10–11 頁；已對照 `../V4_book_content.md` 與原圖 `../V4_book_pictures/V4_10-11.webp`，逐題核對：cats 3、roosters 4、donkeys 5、pigs 7、horses 9、dogs 2、goats 1、bulls 10。
- 隨機練習：使用相同動物與 How many…do you see? / I see…句型，8 種動物 × 1–10 隻＝80 組。清楚標示教材延伸，不宣稱每個數量出自課本。每輪不重複；可選 4、8、16 題。課本模式最多 8 題。
- 測量的是看圖數量辨識及問句理解。隱藏題目模式增加聽力需求，沒有自動口說評量。第一次答對率與合作星、教師確認跟讀分開記錄。
- 原課本及既有遊戲未修改。3D 動物為程式建立的教學模型，並非課本原插圖。正式題目無 unresolved 項目，未使用其他未核對頁面。

## 課堂操作

建議全班分 2–4 隊 → 教師全螢幕投影 → 全班一起數／比手指 → 當輪代表按答案 → 全隊說答案 → 教師確認跟讀或選「尚未跟讀，先前進」。不限時，錯答可重試。代表可使用滑鼠、觸控或按鍵 1/2/3；R 重播題目，P 暫停。左右旋轉可幫助確認動物位置。每隊分數為完成題目數，沒有競速獎勵。

## 固定語音資料集

`audio/` 共有 88 個 Google Cloud Chirp 3 HD MP3：8 個問句及 80 個完整答案。聲線 `en-US-Chirp3-HD-Aoede`，總計 1,585 字元。`audio/manifest.json` 包含文字、路徑、聲線、字元數、請求雜湊與音檔 SHA-256。

合成前使用者確認本月免費剩餘至少 2,500 字元。本次字元數低於該額度；沒有登入帳務查核最終帳單。官方定價：https://cloud.google.com/text-to-speech/pricing 。未做自動重試。

遊戲只播放本地 MP3，不呼叫 Google、不含 API key，也不呼叫瀏覽器 TTS。缺檔／播放失敗時顯示文字供老師朗讀。`build_audio.py` 是製作工具，平常不需執行；既有檔案雜湊相符即跳過，檢查結果 88 個 cached、0 待合成字元。若日後真的缺檔，應先確認當月免費餘額，再明確傳入 `--generate --confirmed-free-remaining ... --key-file ...`；API key 只在工具記憶體內讀取，不寫入輸出。

## 驗證與界線

實際瀏覽器通過：8 題課本一輪、16 題不重複隨機一輪、4 隊各 4 分、首次答錯記錄、連按防重複計分、鍵盤、暫停時封鎖答案、重播、跟讀與略過跟讀、結果、錯題重練及重開。88 個 MP3 全部可由 Web Audio 解碼；88 個快取雜湊相符。390px 螢幕無橫向溢出。3D 場景已視覺檢查，幾何資源重用（3 組），16 題循環無 JS 例外。

尚未實測真實教室音響、投影後排可讀性、實體觸控螢幕；未人工聆聽全部 88 個音檔。上課前請播放範例確認音量。未公開部署。

## 設計決策

採本地 Three.js 0.160.1，授權見 `vendor/THREE-LICENSE.txt`。同屏固定牧場讓數量成為場景的真實狀態，避免用反應速度取代語言學習；透視相機提供受限角度旋轉，不讓幼童迷失。只建立一組共用幾何及共用材質，不逐題累積模型資源。沒有外部 CDN、模型下載或雲端同步需求。
